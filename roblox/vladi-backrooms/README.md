# VLADI BACKROOMS

Proyecto de terror cooperativo 3D para Roblox, con cámara en tercera persona.

## Estado

Fase inicial: estructura de desarrollo. Todavía no hay una experiencia jugable ni recursos externos incorporados.

## Objetivos

- Escenario original inspirado en espacios liminales y Backrooms.
- Hasta seis jugadores cooperativos.
- Criatura original inspirada en la atmósfera de Verity, sin copiar activos de terceros.
- Linterna, exploración, persecuciones, escondites y acertijos.
- Controles PC y móvil.

## Organización

- `src/client`: scripts del cliente.
- `src/server`: lógica del servidor.
- `src/shared`: módulos compartidos.
- `assets`: recursos originales o con licencias verificadas.
- `default.project.json`: proyecto Rojo para sincronizar con Roblox Studio.

## Próximos pasos

1. Auditar licencias y código de bases externas antes de reutilizarlas.
2. Instalar Roblox Studio y Rojo para probar el proyecto.
3. Crear prototipo del primer escenario, con cámara de tercera persona.

> El repositorio `juegos` es público: no subir claves, tokens, ni recursos de terceros sin autorización.
