# VLADI · Clásica 777
Máquina de tres rodillos, una línea central y créditos virtuales. 2.000 fichas iniciales; apuestas de 20, 40, 100, 200 y 500. Rodillos independientes con pesos 18/15/12/9/6/3/1. Premios triples 8/12/18/30/60/150/1200, dos cerezas ×1 y una ×0,25. Retorno teórico 88,355255%; no garantiza resultados individuales. Web Crypto para cada parada; sin alteración de probabilidades por saldo ni historial.

Interfaz PC y móvil, teclado, palanca por toque o arrastre, tabla de premios, música instrumental Web Audio y efectos. Créditos e historial locales, tirada pendiente persistida antes de animar para recuperar exactamente su resultado tras recarga. Sin dinero real, depósitos, retiros, apuestas online ni compras.

Verificación: npm test (tabla completa, contabilidad y 262.144 combinaciones ponderadas), node --check client.js, bash scripts/build.sh. Browser QA y escucha en equipos reales pendientes.

Publicado íntegramente en GitHub Pages: https://vladyerik.com/vladi-tragamonedas/ . HTML, CSS, módulos JavaScript y portada están en esta carpeta. No requiere servidor para jugar; la carga inicial usa internet y las fichas se guardan localmente en este dominio.
