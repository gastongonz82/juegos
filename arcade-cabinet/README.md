# VLADYERIK ARCADE — gabinete físico (prototipo)

Proyecto experimental separado de la web pública.

## Principios
- No modificar archivos existentes ni la rama main.
- Menú navegable con teclado: flechas / WASD, Enter para abrir, Escape para volver.
- Controles USB arcade configurables como teclado; compatibilidad Gamepad API en una fase posterior.
- Un jugador por defecto; dos jugadores solo cuando el juego soporte multijugador local.
- No asumir que los juegos online funcionan sin conexión.
- Revisar rutas y licencias de recursos antes de preparar una distribución offline.

## Primeros juegos candidatos
Space Invaders, Arkanoid, Tetris, Vladi Kong y Vladi Commando.

## Validación antes de publicar
1. Inventariar las rutas reales y los controles de cada juego.
2. Probar navegación completa sin mouse.
3. Probar pantalla completa en monitor 16:9 y 4:3.
4. Probar retorno seguro al menú.
5. Confirmar que no se altera la web pública.
